# May 2026

## Done

### Stability & DX
- **Fixed Issue #59**: Restored 3-letter keyword search and fixed Bloom Filter false negatives.
- **Fixed Issue #60**: Added `--version`, `--help`, and improved path discoverability for global installs.
- **Fixed Issue #61**: Decoupled session data from the Git repository; Engram now defaults to `~/.engram` for storage.
- **Fixed Issue #62**: Eliminated `NaN` stats and fixed crashes on fresh installations with empty indices.

### Autonomous Learning
- **Implemented Issue #67**: Added an autonomous background learning loop integrated into the MCP server. It automatically runs consolidation, contradiction detection, and assertion management.
- **Implemented Issue #63**: Enabled MCP resource subscriptions, providing real-time updates to agents when the memory state changes.

### Agentic Collaboration
- **Enhanced Issue #64**: Upgraded the agent-to-agent handoff protocol to include project health, key decisions, and recent learnings within a token budget.
- **Enhanced Issue #66**: Improved cross-session diffing to analyze decision deltas and code changes, providing deeper insights for multi-agent workflows.

### Documentation
- **Implemented Issue #68**: Updated the README with a "Premium Autonomous Ledger" hook to better position the project for developers.

### Web UI (Premium Dashboard)
- **Implemented Issue #71**: Dashboard redesigned with Memory Health (confidence/tensions), activity feed, learning velocity chart, and Obsidian/Emerald color palette across graph and UI.

### Session Replay (Issue #65)
- **Implemented `session_append_event` MCP tool**: Agents can now push real-time events (decisions, rejections, experiments, results) to an in-progress session.
- **Real-time subscription**: Subscribers to `engram://replay/{project}/{session_id}` receive `notifications/resources/updated` when events are appended or a session is saved with events.
- **Events in `remember`**: The `remember` tool now accepts an optional `events` array for capturing timeline events when saving a session.

### Core Refactors
- **Binary embeddings storage**: Vector search now uses binary format for faster load and smaller cache.
- **Bloom filter fixes**: Minimum item clamping, hash calculation fix, 3-letter keyword support, filter treated as hint (not gate).
- **Path resolution**: Prefers `~/.engram` by default with smarter fallback logic.
- **CLI polish**: `--help` and `--version` added to `remember` and `save-session`.
